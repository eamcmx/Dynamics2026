# Dynamics2026 — Robot Dynamics & Maths Foundations

Interactive, single-page HTML lectures, published with GitHub Pages.

**Live site base:** https://eamcmx.github.io/Dynamics2026/

Every lecture links straight to its published page — click and go. Each lecture lives in its own folder under `lectures/` as an `index.html`. Folders ending in `b` are alternate takes of the same lecture.
