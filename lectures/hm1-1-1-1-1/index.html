Lecture 01 · Linear Algebra · Matrices

Matrices: definitions, operations & properties

From rectangular arrays to a small algebra you can compute with — addition, scalar multiplication, the row-by-column rule, and the structural types that show up everywhere downstream.

Lecturer. bibliosense Lecture. 01
Today we treat a whole grid of numbers as a single object. That sounds modest, but it lets us write a system of equations, a coordinate change, or a quantum measurement as one symbol $A$ and then do algebra on it. We'll define what a matrix is, fix the notation, work out the four core operations — equality, scalar multiplication, addition, and the row-by-column product — and then meet the special shapes (diagonal, identity, zero, triangular, transpose, symmetric) that the rest of the course will keep returning to.

0 What this lecture covers

We start with the basic definitions: what a matrix is, how we name its entries, and what it means for two matrices to be equal. Then we build the four core operations — scalar multiplication, addition, multiplying a row by a column, and the general matrix product — and stress-test them on small numerical examples.

The second half is structural. We classify matrices by shape: square, diagonal, identity, zero, triangular, transposed, symmetric and skew-symmetric. The Kronecker delta $\delta_{i,j}$ gives us a clean tool for proving the identity-matrix theorem, and we close with the algebraic properties — associativity, distributivity, the transpose-of-a-product rule — that justify treating $A,B,C$ a lot like ordinary numbers (with one big exception: $AB \neq BA$ in general).

If you only remember one thing: a matrix is one object you can compute with, not a bag of numbers. Everything else in this lecture is bookkeeping that makes that idea precise.
Why we care. Matrices encode systems of linear equations, differential equations, quantum observables, internet-era cryptography, and graphics transforms — all with the same algebra.

1 Basic definitions: size, entries, notation

A matrix is a rectangular array of numbers (or symbols, or functions) that we agree to add and multiply by certain rules. We write matrices with capital letters $A, B, C, \ldots$

The size of a matrix is the pair (rows, columns). An $m \times n$ matrix (read m-by-n) has $m$ rows and $n$ columns; $m$ and $n$ are its dimensions. Two matrices have the same size when their dimensions agree.

The individual numbers inside the array are its entries or matrix elements. The entry in row $i$, column $j$ of $A$ is written $a_{i,j}$ or $A_{i,j}$ — row first, column second. A short form for the whole matrix is $A = \|a_{i,j}\|$.

A matrix with a single row is a row matrix; a single column is a column matrix. A matrix with the same number of rows as columns is square, and the count is its order — an $n \times n$ matrix is of order $n$.

Row first, column second. Forever. The number of bugs this convention prevents over a career is genuinely large.
Indexing trap. $a_{2,3}$ means row 2, column 3. Don't read it as a coordinate $(x,y)$ — that flips the order.

2 Equality and scalar multiplication

Two matrices $A = \|a_{i,j}\|$ and $B = \|b_{i,j}\|$ are equal when they have the same size and their entries match position-by-position: $a_{i,j} = b_{i,j}$ for every $(i,j)$. Different sizes ⇒ not equal, no matter what the entries look like.

Scalar multiplication. Any matrix $A$ can be multiplied on the left or right by a scalar $\lambda$. The result $B = \lambda A$ has the same size as $A$, with $b_{i,j} = \lambda\, a_{i,j}$ — every entry gets multiplied.

Scalar multiplication is the easy operation. The scalar passes through the matrix and touches every cell, end of story.
Equality is strict. Same size and same entries pairwise. A 2×3 and a 3×2 are never equal, even if they share the same six numbers.

    | 1   4  1 |             |  5   20   5 |

3 The sum of matrices

If $A$ and $B$ are matrices of the same size, their sum $C = A + B$ is the matrix of that same size with $c_{i,j} = a_{i,j} + b_{i,j}$ — entries add componentwise.

If the sizes differ, the sum is simply not defined.

It's componentwise. Addition never mixes positions. The entry at $(i,j)$ in $A+B$ depends only on the entries at $(i,j)$ in $A$ and $B$.
adding two 2×3 matrices

    | 1  2   0 |        | 4    1  2 |

A + B = |  9  -8  2 |

4 Multiplying a row by a column

This is the atom out of which all matrix multiplication is built.

Let $A$ be a row matrix with $n$ entries and $B$ a column matrix with $n$ entries. Their product is the single number

$AB = a_{1,1} b_{1,1} + a_{1,2} b_{2,1} + \cdots + a_{1,n} b_{n,1} = \sum_{k=1}^{n} a_{1,k}\, b_{k,1}.$

In words: pair up the corresponding elements, multiply each pair, sum the results. A row times a column gives a number — and any number can be regarded as a $1 \times 1$ matrix.

For a two-row matrix times a column, do this once per row; the answer is a column with one entry per row of $A$. The general $m \times n$ pattern works the same way: each row of the left matrix shakes hands with the column on the right.

Every matrix product, no matter how big, is just rows-meet-columns repeated. Internalise this one rule and the rest is bookkeeping.
Length must match. You can only pair a row with a column when they have the same number of entries — that's the dimensional precondition for matrix multiplication.

5 Matrix multiplication: the general rule

The product $AB$ is defined only when the number of columns of $A$ equals the number of rows of $B$. If $A$ is $m \times l$ and $B$ is $l \times n$, then $C = AB$ is $m \times n$, and

$c_{i,j} = \sum_{k=1}^{l} a_{i,k}\, b_{k,j}.$

That is, the $(i,j)$ entry of $AB$ is the $i$-th row of $A$ multiplied by the $j$-th column of $B$.

For a square matrix, repeated products are written as powers: $A^2 = A\cdot A$, $A^3 = A\cdot A\cdot A$, and $A^n = A \cdots A$ ($n$ factors).

Crucial warning. Matrix multiplication is not commutative in general: even when both $AB$ and $BA$ are defined and have the same size, usually $AB \neq BA$.

Order matters. $AB$ and $BA$ are different operations the way 'add salt, then water' and 'add water, then salt' are different recipes.
AB ≠ BA in general. This is the single biggest break from ordinary number algebra. Whenever you manipulate a matrix expression, never silently swap the order of a product.
Dimensional gate. Inner dimensions must match: $(m \times l)\,(l \times n) = (m \times n)$. If the inner numbers don't agree, the product simply doesn't exist.

    | 0 3 |        |  4 -1 |

AB = | 10  9 |     BA = |  6 18 |
     | 12 -3 |          |  8  1 |

6 Worked examples

(a) Solving a matrix equation. Given $A = \begin{pmatrix}1 & -3\\ 2 & 4\end{pmatrix}$ and $B = \begin{pmatrix}4 & 10\\ 5 & 15\end{pmatrix}$, solve $X + 4A = B$ for $X$:

$X = B - 4A = \begin{pmatrix}4 & 10\\ 5 & 15\end{pmatrix} - \begin{pmatrix}4 & -12\\ 8 & 16\end{pmatrix} = \begin{pmatrix}0 & 22\\ -3 & -1\end{pmatrix}.$

(b) A row times a column, and the column times the row. With $A = (1\ 2\ 3)$ and $B = (5,\, -4,\, 0)^T$, $AB$ is a single number ($-3$), but $BA$ is a $3\times 3$ matrix — so $AB$ and $BA$ aren't even the same size.

(c) Spotting a pattern. For $A = \begin{pmatrix}1 & 1\\ 0 & 1\end{pmatrix}$, computing $A^2, A^3, A^4$ shows the top-right entry counts the power: $A^n = \begin{pmatrix}1 & n\\ 0 & 1\end{pmatrix}$. So $A^{2002} = \begin{pmatrix}1 & 2002\\ 0 & 1\end{pmatrix}$.

Examples (b) and (c) are worth re-doing by hand. (b) cures the instinct to think $AB$ and $BA$ are 'basically the same'; (c) shows how powers of structured matrices stay structured — a theme we'll return to.
Pattern-finding pays. You almost never compute $A^{2002}$ by brute force. Compute $A^2, A^3$, conjecture the pattern, and either verify or prove it by induction.
successive powers reveal the pattern
A   = | 1 1 |   A^2 = | 1 2 |   A^3 = | 1 3 |   A^n = | 1 n |
      | 0 1 |        | 0 1 |        | 0 1 |        | 0 1 |

7 Types of matrices: diagonal, identity, zero, triangular

In a square matrix $A$, the entries $a_{i,i}$ form the leading (principal) diagonal.

Diagonal matrix. A square matrix whose off-diagonal entries are all zero: $a_{i,j} = 0$ whenever $i \neq j$.

Identity matrix $I$. A diagonal matrix whose diagonal entries are all $1$. It satisfies $IA = A$ and $AI = A$ — the matrix analogue of the number $1$.

Zero matrix $0$. Every entry is $0$. It satisfies $A \cdot 0 = 0 \cdot A = 0$ and $A + 0 = A$. However, $AB = 0$ does not imply $A = 0$ or $B = 0$ — there exist non-zero matrices whose product is the zero matrix.

Triangular matrices. A square matrix is upper-triangular if every entry below the diagonal is zero ($a_{i,j} = 0$ for $i > j$), and lower-triangular if every entry above the diagonal is zero ($a_{i,j} = 0$ for $i < j$).

Zero divisors exist. Take $A = \begin{pmatrix}0 & 1\\ 0 & 4\end{pmatrix}$ and $B = \begin{pmatrix}3 & 2\\ 0 & 0\end{pmatrix}$. Both are non-zero, but $AB = 0$. Matrix algebra has zero divisors; ordinary number algebra does not.
Identity is the multiplicative '1'. Compare $1 \cdot a = a \cdot 1 = a$ with $I A = A I = A$. The identity matrix is genuinely playing the role of $1$.

8 Transpose, symmetric and skew-symmetric matrices

Given an $m \times n$ matrix $A = \|a_{i,j}\|$, its transpose $A^T$ is the $n \times m$ matrix obtained by swapping rows and columns: $(A^T)_{i,j} = a_{j,i}$. Rows of $A$ become columns of $A^T$, and vice versa.

A square matrix $A$ is symmetric if $A^T = A$, equivalently $a_{i,j} = a_{j,i}$ — the entries are mirror-images across the diagonal.

It is skew-symmetric if $A^T = -A$, equivalently $a_{i,j} = -a_{j,i}$. Setting $i = j$ in this last identity forces $a_{i,i} = -a_{i,i}$, so the diagonal of a skew-symmetric matrix is all zeros.

Symmetric matrices show up everywhere — covariance matrices, quadratic forms, the Hessian. Skew-symmetric ones show up in rotations and angular velocity. Worth recognising on sight.
Quick check. To test symmetry, fold the matrix along the diagonal. To test skew-symmetry, do the same and check that opposite entries differ only by sign — and that the diagonal is zero.

9 The Kronecker delta and the identity-matrix theorem

The Kronecker delta symbol is

$\delta_{i,j} = \begin{cases}1, & i = j,\\ 0, & i \neq j.\end{cases}$

Its magic property is that it cancels a summation index. Inside a sum like $\sum_i a_{i,k}\, \delta_{i,j}$, every term where $i \neq j$ vanishes, so only the $i = j$ term survives:

$\sum_{i=k}^{n} a_i\, \delta_{i,j} = a_j \quad (k \le j \le n), \qquad \sum_{i=k}^{n} a_i\, \delta_{i,j} = 0 \ \text{otherwise}.$

Theorem. The matrix $I = \|\delta_{i,j}\|$ — i.e. ones on the diagonal, zeros elsewhere — is the identity matrix.

Proof sketch. Take any $m \times n$ matrix $A$ and the $n$-th order identity $I = \|\delta_{i,j}\|$. Then $(IA)_{i,j} = \sum_{k=1}^{n} \delta_{i,k}\, a_{k,j} = a_{i,j},$ because only the $k = i$ term survives. Entries match pairwise, so $IA = A$. ∎

Why bother with δ? Once you can write 'the identity matrix' as $\delta_{i,j}$ inside a sum, identity-related proofs collapse to one line. The same trick reappears in tensor calculus and physics.
the delta cancels the sum
sum_{i=1}^{100}  i^2 · δ_{i,3}   =   3^2 = 9
sum_{k=1}^{20}   2k · δ_{k,10}   =   2·10 = 20
sum_{k=1}^{5}    2k · δ_{k,10}   =   0       (10 not in range)

10 Algebraic properties of matrix operations

Addition. For matrices of the same size:

  • An opposite matrix exists: $A + (-A) = 0$.
  • Commutative: $A + B = B + A$.
  • Associative: $(A + B) + C = A + (B + C)$.
  • Transpose distributes: $(A + B)^T = A^T + B^T$.

Multiplication. Whenever the products are defined and $\lambda, \mu$ are scalars:

  • $(\lambda \mu) A = \lambda(\mu A)$.
  • $\lambda(AB) = (\lambda A)B = A(\lambda B)$.
  • Associative: $(AB)C = A(BC)$.
  • Transpose of a product reverses the order: $(AB)^T = B^T A^T$.
  • Two diagonal matrices of the same order commute: $AB = BA$.

Mixed.

  • Distributive on the left: $A(B + C) = AB + AC$.
  • Distributive on the right: $(A + B)C = AC + BC$.
  • Scalar over a sum: $\lambda(A + B) = \lambda A + \lambda B$.

Bottom line. Matrices behave a lot like real numbers — except for non-commutativity of multiplication, the existence of zero divisors ($AB = 0$ without $A=0$ or $B=0$), and the order-reversal in $(AB)^T = B^T A^T$. A $1\times 1$ matrix $\|a_{1,1}\|$ behaves exactly like the number $a_{1,1}$, so the matrix algebra is a genuine generalisation of ordinary arithmetic.

Three things to memorise on sight: $(AB)^T = B^T A^T$ (reverse the order!), $(AB)C = A(BC)$ (associativity is your friend), and $AB \neq BA$ in general. The rest you can re-derive.
Transpose flips order. $(AB)^T = B^T A^T$, not $A^T B^T$. The same flip happens for matrix inverses later: $(AB)^{-1} = B^{-1} A^{-1}$.
Polynomial in a matrix. Because addition, scalar multiplication, and powers all make sense, you can plug a square matrix into a polynomial: if $f(x) = x^2 - 2x + 1$, then $f(A) = A^2 - 2A + I$. The constant term becomes the identity, not the number 1.
